# 1415. The k-th Lexicographical String of All Happy Strings of Length n

## What it asks (own words)
A "happy" string uses only a, b, c and never repeats a letter twice in a row. List all happy strings of length n in sorted order and return the k-th one (or "" if there are fewer than k).

## Key constraints
- 1 <= n <= 10, 1 <= k <= 100. Plain backtracking would also pass; the direct construction is just tidier.

## Approach
There are `3 * 2^(n-1)` happy strings. Using a 0-based rank: the first letter is `'abc'[rank / 2^(n-1)]`. Each following position has exactly two allowed letters (the ones different from the previous letter, in alphabetical order), so the rank picks one of them with the next bit.

## Why it works
In sorted order, all strings with a smaller letter at the first differing position come first, and each choice leads to an equal-sized subtree. So the rank decodes as mixed-radix digits (3, then 2, 2, ...).

## Edge cases
- k beyond the total returns "".
- n = 1: just 'a', 'b', 'c'.

## Complexity
- Time: O(n)
- Space: O(n)

## Testing note
For every n up to 10 and k up to 100, compared against the list generated by DFS in lexicographic order.

## Reusable pattern
**k-th lexicographic object with equal-size subtrees: decode k in mixed radix instead of enumerating.** (DFS with a counter is the backtracking fallback.)
